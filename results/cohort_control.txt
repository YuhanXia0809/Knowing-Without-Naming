====================================================================================================
CUE-NARROWING / COHORT-SIZE CONTROL ANALYSIS
'Knowing Without Naming' (Findings of EACL 2027) -- cohort-size control
====================================================================================================

CLAIM TESTED.  The first-unit cue works only because it shrinks
the candidate set, so unlocking under the cue does not show the
target was available beforehand.

TESTABLE CONSEQUENCE.  If narrowing is the whole story, the cue's
benefit must scale with how much the first unit narrows the cohort.
Cohort sizes differ by up to two orders of magnitude within each
language, so this is a high-powered test.

COHORT DEFINITION (primary).
  English: number of distinct orthographic types in the CLEARPOND
    English lexicon (27,751 SUBTLEX-US-attested word forms, every
    one >= 0.33 occurrences per million) that begin with the same
    letter as the cued word.  Analyses use log10(count + 1).
  Chinese: number of CC-CEDICT simplified headwords (120,968) that
    begin with the same character as the cued word (the Chinese cue
    is the first character).  log10(count + 1).
  Sensitivity variants per language are reported in analysis 1.
  Cohort size is only ever compared WITHIN a language, so the two
  languages using different resources is harmless.

DATA NOTES / PROBLEMS ENCOUNTERED.
  * The Chinese cohort is counted in CC-CEDICT rather than in the
    MoE Revised dictionary the bank's glosses come from; SUBTLEX-CH
    is the frequency-attested alternative.
  * SUBTLEX-CH-WF covers only 642 of the 689 distinct target first
    characters (47 missing); CC-CEDICT misses only 6, which is why
    CC-CEDICT is the primary Chinese resource.
  * Every CLEARPOND entry already clears 0.33 per million, so a
    'Zipf floor' variant is implemented as freq >= 1 per million.
  * The recorded `cue` field equals the cued word's first unit in
    100% of rows in both languages and both arms (verified when
    this analysis was written), so the cohort can be keyed on the word itself.
  * English has only 26 distinct first letters, so the log-cohort
    regressor takes 26 values; item-clustered SEs are reported as
    specified but first-unit-clustered SEs and a 26-point
    letter-level aggregate are reported alongside them.

lexicon sizes: CLEARPOND 27751 types (26 first letters); WordNet 3.1 77568 lemmas; CC-CEDICT 120968 headwords (10825 first characters); SUBTLEX-CH 99121 types

3  BOTTOM LINE
   * The English fit-matched margin (61.8% target vs 32.9% decoy)
     is essentially untouched by cohort size: adding log cohort
     attenuates the target coefficient by only 1.4%, and within
     every cohort tercile the target still leads the decoy by
     26.0 to 30.7 points.
   * The target's own unlock rate is insensitive to cohort size in
     English and moves the WRONG WAY in Chinese, so the size of the
     search space the cue leaves open is not what drives recovery.
   * In Chinese the target-over-decoy margin GROWS with cohort size
     (interaction b=+0.647, p=0.0005 on the matched population): the
     target's advantage is concentrated exactly where the cue
     narrows LEAST, which a narrowing account cannot produce.
   * Chinese remains the weak cell: at matched fit the target-decoy
     margin is ~0 (as already reported by fit_ci), and cohort control
     does not rescue it. The Chinese contribution here is the
     wrong-signed cohort slope, which damages the narrowing account
     without supporting the availability account.
